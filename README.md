# Mandelbrot Set Visualization

A Mandelbrot set visualization written in C/C++ and CUDA, using GPU parallelization to enable fast, deep-zoom renders. The project uses the [SDL3 library](https://www.libsdl.org/) (included as a git submodule) to display the render live in a window.

## About Mandelbrot and This Project

The Mandelbrot set is generated by iterating the complex recurrence **z<sub>n</sub> = z<sub>n-1</sub><sup>2</sup> + c** for different complex numbers *c*.

A complex number can be represented as a point on the complex plane - the x-axis holds the real part, the y-axis the imaginary part. This plane is mapped onto the SDL window, so each pixel corresponds to one complex number *c*.

The renderer uses an **escape-time algorithm**: for each pixel it counts how many iterations it takes for the series to exceed a fixed threshold (or caps out at a maximum iteration count if it never escapes). Coloring each pixel by its iteration count produces the fractal image.

To support very deep zooms without losing precision, the algorithm is based on **perturbation theory**:
- One high-precision reference orbit is calculated once on the CPU (using `long double`).
- All other pixels are then computed on the GPU as small *deltas* relative to that reference orbit, which lets them stay in fast, low-precision `double` arithmetic even at extreme zoom levels.

> **Note:** MSVC treats `long double` the same as `double`, which limits achievable zoom depth on Windows. For deeper zooms, building on Linux with a compiler that has real 80-bit `long double` support (e.g. GCC) is recommended.

The GPU writes the computed iteration counts into CUDA managed memory, which the CPU then reads to apply coloring and draw the pixels to the window (or to export an image).

## Features

### Keybinds
| Key | Action |
|---|---|
| Mouse scroll or `+` / `-` | Zoom in / out at cursor |
| Arrow keys | Move up / down / left / right |
| Hold `LShift` | Zoom centered on the view instead of the cursor |
| `C` | Cycle through color modes |
| `F` | Flip the zoom factor (mirrors the image on the x-axis) |
| `R` | Reset to the default view |
| `P` | Export the current view as an image (`.ppm`) |
| `Esc` / close window | Quit the program |

### Program Arguments
- First two arguments set the window width and height: `./mandelbrot 900 700`
- `--cm:<int>` - set the color mode the program starts with, e.g. `./mandelbrot 900 700 --cm:3`
- `--db` - enable debug mode (marks the center pixel), e.g. `./mandelbrot 900 700 --db`
- `--eRes:<float>` - set the export resolution multiplier, e.g. `./mandelbrot 900 700 --eRes:3.0`
  - Renders the current view at a much higher resolution when exporting with `P`, without changing the live window resolution.

If arguments are missing or invalid, the program falls back to a default 300x300 window.

## How Do I Build and Run This Project?
> Note: Because this project depends on several specific tools (CUDA Toolkit, a compatible compiler, SDL3, CMake) and setups vary a lot between machines, I can't guarantee it will build and run out of the box on yours. Below are the exact steps that worked for me on Windows and Linux.

<details>
<summary><b>Linux</b> (recommended)</summary> 
  
  1. Install the following
      - (git)
      - (make)
      - CMake
      - C++ compiler 
      - [CUDA Toolkit](https://developer.nvidia.com/cuda/toolkit) matching your GPU
  2. Clone this repo **with submodules**:
     ```sh
     git clone --recurse-submodules https://github.com/Inoyuuuuu/mandelbrot.git
     ```
  3. Open the project (e.g. in VS Code and select your C++ compiler).
  4. Generate Makefiles with command:
     ```sh
     cmake .
     ```
  5. Build executable with command:
     ```
     make
     ``` 
  6. Run the executable:
     ```sh
     ./mandelbrot
     ```
</details>

<details>
<summary><b>Windows</b></summary>
  
1. Install the following
    - git
    - CMake
    - [C++ Build Tools](https://visualstudio.microsoft.com/de/visual-cpp-build-tools/)
    - [CUDA Toolkit](https://developer.nvidia.com/cuda/toolkit) matching your GPU
2. Clone the repo **with submodules**:
   ```sh
   git clone --recurse-submodules https://github.com/Inoyuuuuu/mandelbrot.git
   ```
3. Open the project (e.g. in VS Code and select your C++ compiler).
4. Generate build files with command (or similar, depending on your setup):
   ```sh
   cmake -G "Visual Studio 18 2026" -A x64
   ```
5. Build executable with command:
   ```sh
   cmake --build . --config Release
   ```
6. Navigate to `build/Release` and run the executable with:
   ```sh
   ./mandelbrot
   ```
</details>

A CUDA-free version (CPU only) is available on the [`without-cuda`](https://github.com/Inoyuuuuu/mandelbrot/tree/without-cuda) branch.
